What this PR does

  • Adds a new entry to the jobTierPatterns list in setJobTier (pkg/variantregistry/ocp.go).
  • Any job whose (lowercased) name contains -e2e-nutanix-upgrade is now classified as candidate tier.
  • Candidate tier means the job is excluded from default Component Readiness views but data is still synced, so it can be promoted later once stable.
  • Comment cites CSI operator conformance failures as the reason for instability.
  • 3 lines added, 0 removed, 1 file changed — purely additive.
