Verdict

APPROVE

This is a well-scoped, mechanical lint cleanup. Every parameter/variable rename I spot-checked was safe (ESLint had already confirmed those bindings were unused inside their scope), and the one genuine dead-code removal (in ComponentReadiness.jsx) leaves no orphaned references. The only real concern is a handful of places where entire dead functions/state (not just unused params) were underscore-prefixed rather than deleted, which is inconsistent with the cleanup precedent set elsewhere in the same PR — worth a follow-up pass but not a blocker.

What this PR does

  • Fixes all 136 pre-existing no-unused-vars ESLint warnings across 64 sippy-ng files.
  • Prefixes unused function params, destructured values, and catch-clause errors with _ to match the existing argsIgnorePattern/varsIgnorePattern: '^_' config, and adds a matching caughtErrorsIgnorePattern.
  • Removes some genuinely dead code (e.g. unused useTheme()/useLocation()/useNavigate() calls, and the copy-link feature in ComponentReadiness.jsx).
  • Flips no-unused-vars from warn to error to lock the rule in going forward.
  • No intended behavioral change anywhere in the diff.
