Straightforward config cleanup. All removed ROSA e2e jobs are already covered by the rosa-stage section's regexp. No CI visibility is lost. No code changes involved.

What this PR does

  • Removes 31 explicit ROSA e2e job entries from the "4.22" release section in config/openshift.yaml.
  • These jobs (OCM FVT staging tests, ROSA Classic/HCP staging tests, ROSA nightly e2e tests, daily status) are ROSA-specific and don't belong under the OCP 4.22 release tracking.
  • The rosa-stage section already captures all of them via the regexp ^periodic-ci-openshift-online-rosa-e2e-main-.*.
  • Some removed nightly jobs covered versions other than 4.22 (4.19, 4.20, 4.21, 5.0), confirming they were misplaced.

No blocking issues, no should-fix items, no nits.
